# 충해전기 미수정리 웹앱 (Streamlit)

매출·매입 세금계산서, 어음수취내역, 은행거래내역을 올리면 **자동으로 종류를 판별**하고
**기존 누적본에 신규만 추가**(중복 제거)해서 지금 양식대로 출력·다운로드합니다.

## 구성
- `app.py` — Streamlit 화면(비밀번호 → 업로드 → 처리 → 다운로드)
- `pipeline.py` — 처리 로직(파일종류 자동판별 + 누적). `engine/engine.py` 재사용
- `engine/engine.py` — 파싱·누적·서식 엔진
- `data/` — 누적 baseline(현재 정리본 + 지원표). 처리할 때 여기에 신규를 더함
- `requirements.txt`, `packages.txt` — 배포 의존성(LibreOffice 포함, .xls·깨진 파일 변환)

## 배포 (Streamlit Community Cloud, 무료)
1. 이 `웹앱` 폴더를 GitHub 저장소(비공개 권장)에 올린다.
2. share.streamlit.io → New app → 저장소·브랜치·`app.py` 선택 → Deploy.
3. App settings → **Secrets** 에 비밀번호 등록(아래 "GitHub 자동저장 설정" 참고. 관리자/보기전용 2종):
   ```
   password_admin = "관리자비밀번호"
   password_view  = "보기전용비밀번호"
   ```
4. 배포되면 공개 URL이 생긴다. 비밀번호로만 접근.

## 사용
1. 비밀번호 로그인.
2. 서울 칸에 서울 자료(매출·매입·어음·은행 신한/기업/하나/농협/우리), 화성 칸에 화성 자료(신한) 업로드.
   - 파일명은 상관없음. 내용(헤더)으로 매출/매입/어음/은행을 자동 판별.
   - 은행이 추가돼도 그냥 올리면 됨(은행 거래내역이면 자동 처리).
3. "처리 시작" → 판별결과·상태요약 확인 → 결과 zip 다운로드.
4. "현재 누적자료 다운로드"로 언제든 누적본 전체를 받을 수 있음.
